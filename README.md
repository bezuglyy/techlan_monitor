# Techlan Monitor

Кастомная интеграция Home Assistant · v1.0.0

![icon](custom_components/techlan_monitor/brand/icon.png)
Мониторинг серверов и устройств techlan.su: доступность, температура, статусы.

## Возможности
- Сенсоры доступности узлов
- Агент мониторинга и установщик
- Автообнаружение устройств сети

## Установка
Скопируйте папку `custom_components/techlan_monitor/` в каталог `custom_components/` конфигурации HA и перезапустите Home Assistant.
